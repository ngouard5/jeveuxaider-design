Couleurs

Palette DSFR : tokens sémantiques (light/dark) à utiliser dans les maquettes, et palette de référence sous-jacente. Source : Figma « DSFR - v1.15.0 - Fondamentaux » (page Couleurs) — même nomenclature que les variables CSS officielles du DSFR (--text-default-grey, --background-action-high-blue-france, etc.).

🔗 Documentation officielle DSFR : Couleurs
À utiliser dans les maquettes : toujours les tokens sémantiques (« Decisions ») ci-dessous — jamais une couleur de la palette brute directement. Un token donné change de valeur hexadécimale entre thème clair et thème sombre ; c'est voulu, c'est lui qui porte le sens (ex. --text-disabled-grey), pas la couleur.

Cohérence avec le code

Confirmé : --text-disabled-grey vaut #929292 en light dans Figma, ce qui correspond à ce qu'on a tranché pour DsfrButton (le code utilisait #656565 par endroits — voir À homogénéiser).

Écart : la palette jva-blue définie dans tailwind.config.ts reprend certaines valeurs DSFR (500: #000091 = blue-france-sun-113, 800/900 = ses états hover/active) mais avec sa propre numérotation Tailwind (50–900), différente de l'échelle DSFR (75–975 + sun/main). Pas un bug, mais à garder en tête : le nom de la classe Tailwind ne renseigne pas sur le token DSFR sémantique correspondant.
