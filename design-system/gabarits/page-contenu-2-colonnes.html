Gabarit — Page de contenu à 2 colonnes

Schéma de composition pour une page de type formulaire ou fiche détaillée avec informations annexes. Structure identique mesurée sur 2 maquettes Figma réelles : édition du profil bénévole, et page mission.

Lecture de maquettes Figma existantes, pas une spécification officielle. Les valeurs en px sont celles mesurées sur les cadres Figma en résolution desktop ; à confirmer avec le développement avant implémentation.

Structure verticale

En-tête — LayoutHeader (≈178px)
Fil d'Ariane — DsfrBreadcrumb
Titre de la page (h1)
Colonne principale — 792px
sections empilées, rythme vertical 40px
Colonne annexe — 384px
Pied de page — LayoutFooter (≈605px)

Corps de page : 792px (colonne principale) + 24px (gouttière) + 384px (colonne annexe) = 1200px. Ces trois mesures sont identiques sur les 2 maquettes analysées, ce qui suggère un vrai gabarit récurrent plutôt qu'une coïncidence.

Anatomie de la colonne principale

Le contenu de la colonne principale est découpé en sections espacées d'un rythme vertical constant (~40px), chacune suivant la même anatomie :

BlocRôle
1. Titre de sectionObligatoire — ex. BaseSectionHeading
2. Texte d'aideOptionnel — ex. BaseFormHelperText / BaseParagraph
3. ContenuChamps de formulaire, description, liste… selon la section

Colonne annexe

Dans les 2 maquettes analysées, la colonne annexe (384px) porte des informations complémentaires plutôt que de l'action principale : récapitulatif, informations clés en paires terme/valeur, ou une alerte contextuelle. Composants à mobiliser en priorité : BaseDescriptionList pour des paires terme/valeur, DsfrAlert ou BaseAlert pour un message contextuel.
