Candidats migration DSFR

Composants réutilisables custom ayant un équivalent DSFR direct, triés par effort de migration croissant. Liste vérifiée manuellement : les composants qui délèguent déjà à un composant Dsfr* en interne ont été exclus, seule la brique partagée non encore migrée est listée.

ComposantUsagesEffortCible DSFRNote
CustomFiltersStatisticsButton
components/custom/FiltersStatisticsButton.vue		 21 Faible DsfrButton + DsfrBadge (compteur)
DSFR officiel : Bouton · Badge		 21 usages mais un seul call-site de composition (bouton + badge de comptage).
BaseTabs
components/base/Tabs.vue		 10 Faible DsfrTabs
DSFR officiel : Onglet		 Même prop `tabs` ; DsfrTabs ajoute juste un `name` pour l'a11y.
BaseAlert
components/base/Alert.vue		 8 Faible DsfrAlert
DSFR officiel : Alerte		 Une seule prop (variant) ; mapping quasi 1:1.
BaseButton
components/base/Button.vue		 5 Faible DsfrButton
DSFR officiel : Bouton		 Doublon quasi-abandonné (5 usages) du bouton principal ; migration = suppression après bascule des 5 appelants.
BaseHrTitle
components/base/HrTitle.vue		 5 Faible DsfrSeparator Pattern identique (trait + libellé centré) déjà implémenté en DSFR sous un autre nom.
BaseTextarea
components/base/Textarea.vue		 5 Faible DsfrTextarea
DSFR officiel : Champ de saisie		 Même jeu de props à peu de chose près (modelValue, error, rows…).
UiButtonLink
components/ui/ButtonLink.vue		 3 Faible DsfrButton (variante tertiaire sans bordure) ou DsfrLink
DSFR officiel : Bouton · Lien		 Bouton HTML custom stylé comme un lien ; remplacement direct.

components/custom/ButtonMissionFavorite.vue		 3 Faible DsfrIconButton
DSFR officiel : Bouton		 Bouton icône brut ; l'animation d'échelle au survol est à reproduire via classes custom sur DsfrIconButton.

BaseModal
