Natif DSFR (pas encore wrappé)

Indicateur de progression DSFR (fr-stepper) pour guider dans un parcours en plusieurs étapes. Composant officiel du DSFR, disponible dans dsfr.min.css, mais pas encore utilisé dans l'application — testé pour l'instant uniquement dans le prototype d'inscription bénévole.

Attributs

Attributs
Attribut / variableRôle
data-fr-current-stepÉtape courante (pour le script DSFR natif — non chargé ici)
data-fr-stepsNombre total d'étapes
--current-step / --stepsVariables CSS utilisées par le dégradé de la barre de progression ; à défaut du script DSFR natif, ce sont elles qu'il faut définir en style inline sur .fr-stepper__steps, comme dans les démos ci-dessus

Règles d'usage (doc officielle DSFR)

8 étapes maximum. Toujours positionner l'indicateur en haut de la page. La navigation entre étapes se fait via les boutons du formulaire, jamais en cliquant sur l'indicateur lui-même. Terminer par une étape de confirmation, sans titre d'« étape suivante » affiché à ce moment-là. Éviter de répéter le numéro de l'étape dans son intitulé (déjà affiché par le composant).

  </p>
