Wrapper DSFR

components/dsfr/SelectAutocomplete.vue

Select DSFR avec recherche texte dans les options.

🔗 Documentation officielle DSFR : Liste déroulante riche

Démo

Le déclencheur a l'apparence d'un select DSFR (fond gris, chevron) ; le champ de recherche et la liste filtrable n'apparaissent qu'au clic, dans un panneau superposé.
