Documentation des composants frontend

JeVeuxAider.gouv.fr — composants réutilisables (≥ 2 usages), analysés automatiquement depuis le code source. 164 composants au total.

Méthodologie. Props, exemples d'usage et statuts DSFR extraits automatiquement du code source (script d'analyse statique). Les démos (onglet « Démo » de chaque page) sont des aperçus visuels statiques reconstruits en HTML à partir des classes réelles des composants et compilés avec la configuration Tailwind du projet — ce ne sont pas des rendus Vue live. Pour les composants applicatifs liés à des données métier, seul l'exemple de code réel est fourni. « DSFR » = Système de Design de l'État ; le dossier components/dsfr/ est l'implémentation maison de ce référentiel.

Fichiers sources : component-inventory.csv, component-inventory-single-use.csv, homogenization-candidates.md.
