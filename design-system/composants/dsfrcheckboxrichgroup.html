DsfrCheckboxRichGroup

5 usages Wrapper DSFR components/dsfr/checkbox-rich-group/index.vue

Groupe de cases à cocher DSFR « riches » (avec description par option).

🔗 Documentation officielle DSFR : Case à cocher

Démo

Compétences recherchées

Chaque option est une carte cliquable (bordure, fond clair au survol) ; l'option cochée passe en bordure et fond bleus, comme dans le vrai composant.

Tester les props

Modifiez les valeurs pour voir le code correspondant se mettre à jour ; pour certains composants, l'aperçu visuel ci-dessous réagit aussi en direct.

Aperçu visuel non disponible pour ce composant — le code ci-dessous reste exact.

Exemple d'usage réel

<DsfrCheckboxRichGroup
        ref="refBenefitsOptions"
        v-model="selectedOptions"
        :options="options"
        name="activites"
        container-class="grid @xl:grid-cols-2 gap-2"
        option-class="text-sm rounded-[4px] py-3 px-4"
        label-class="w-full whitespace-normal"
      >
        <template #default="{ option }">
          <span class="flex items-center justify-between gap-2">
            <span class="line-clamp-2">{{ option.label }}</span>
            <span class="text-sm @xl:text-xl !leading-none">{{ option.icon }}</span>
          </span>
        </template>
      </DsfrCheckboxRichGroup>
