DsfrButton

326 usages

Wrapper DSFR

components/dsfr/Button.vue

Bouton principal du design system, rendu en `<button>`, `<a>` ou `<NuxtLink>` selon le contexte, avec icône et état loading. Le composant le plus utilisé du projet.

🔗 Documentation officielle DSFR : Bouton

Démo

État disabled d'après la maquette Figma (Inscription et connexion) : fond \-disabled-grey #E5E5E5, texte \-disabled-grey #929292. À noter : components/dsfr/Button.vue applique en réalité text-[#656565] pour ce même état — écart entre la maquette et le code à vérifier avec l'équipe dev.

Tester les props

Modifiez les valeurs pour voir le code correspondant se mettre à jour ; pour certains composants, l'aperçu visuel ci-dessous réagit aussi en direct.

Aperçu visuel non disponible pour ce composant — le code ci-dessous reste exact.
