Variantes

Chaque icône existe en 2 versions : Pleine (fill, classe DSFR fr-icon-xxx-fill) et Contour (line, classe DSFR fr-icon-xxx-line). Dans le code JVA, l'équivalent est le composant Vue Ri<Nom>Line / Ri<Nom>Fill de @remixicon/vue — même nomenclature Remix Icon que les icônes Figma, donc correspondance quasi directe entre le nom d'icône Figma et le nom du composant Vue.

Catalogue (480 icônes, 18 catégories)

Vue d'ensemble par catégorie. Pour trouver une icône précise, chercher son nom dans Figma (page Icônes) — les noms suivent la convention Remix Icon (ex. user-heart → RiUserHeartLine/RiUserHeartFill).

Cohérence avec le code

@remixicon/vue est la librairie dominante (220 fichiers) et correspond exactement au set d'icônes DSFR/Figma ci-dessus — c'est la bonne à utiliser pour toute nouvelle maquette.

Écart : @heroicons/vue (4 fichiers) et vue-remix-icons (1 fichier, package legacy) sont aussi présents dans package.json mais hors convention — leurs icônes ne correspondent pas au set DSFR officiel. À ne pas reprendre pour du nouveau travail ; candidats à une migration vers @remixicon/vue.
