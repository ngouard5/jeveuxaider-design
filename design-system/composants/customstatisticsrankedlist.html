CustomStatisticsRankedList

components/custom/StatisticsRankedList.vue

Liste classée (avec médailles optionnelles) pour les tops de statistiques.

Démo

  1. 🥇
    Les Restos du Cœur — 128 missions
  2. 🥈
    Croix-Rouge française — 97 missions
  3. 🥉
    Secours populaire — 82 missions

Retire les séparateurs entre lignes (le composant utilise BaseStackedList avec divided="false") et agrandit les médailles dans une colonne fixe de 64px, comme dans le vrai rendu.

Modifiez les valeurs pour voir le code correspondant se mettre à jour ; pour certains composants, l'aperçu visuel ci-dessous réagit aussi en direct.
