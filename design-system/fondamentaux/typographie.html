Police principale : Marianne (Light/Regular/Medium/Bold, déjà chargée dans ce repo). Police secondaire : Spectral (serif, réservée aux informations secondaires ou mineures via la classe DSFR fr-text--alt) — non embarquée ici, rendue en Georgia par repli.

Cohérence avec le code

L'échelle fontSize de tailwind.config.ts (xxs → 6xl, ex. 30px/36px/60px) est une échelle générique, pas mappée sur les paliers DSFR ci-dessus (12/14/16/18/20 pour le corps de texte, 20 à 40 pour les titres, 48 à 80 pour les titres alternatifs). En pratique le code applique surtout text-sm/text-base/text-lg pour le corps de texte, ce qui reste proche du DSFR (14/16/18px) ; les tailles au-delà (3xl et plus) n'ont pas d'équivalent DSFR direct et sont à éviter dans une maquette conforme — préférer les titres/titres alternatifs ci-dessus.
