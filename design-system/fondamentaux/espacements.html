🔗 Documentation officielle DSFR : Espacement

Unité : « v », incréments de 4px (0,25rem). Échelle continue de 0-5v (2px) à 32v (128px), plus des valeurs négatives (préfixe n, ex. n2v = -8px) pour les marges négatives. 0 ne prend pas d'unité.

⚠️ Unité « w » (multiples de 8px) : présente dans l'ancienne doc DSFR mais dépréciée — ne pas l'utiliser dans de nouvelles maquettes, préférer systématiquement « v ».

Usage en classes DSFR

Les classes utilitaires DSFR combinent propriété + côté + valeur, ex. fr-mb-4v (margin-bottom 16px), fr-py-2v (padding vertical 8px), fr-mt-n2v (margin-top -8px).
