Badge d'état générique (shadcn), utilisé pour seulement deux libellés d'état — voir section homogénéisation.

🎨 Figma seulement

Démo

Le composant délègue le rendu à DsfrBadge selon un mapping state → type défini dans components/ui/BadgeState.vue (voir Code) : chaque libellé métier (français ou clé technique) est traduit vers l'un des types visuels du badge DSFR.

ValidéeEn attente de validationEn cours de traitementRefuséeAnnuléeBrouillon

Mapping réel (components/ui/BadgeState.vue) : Validée/validated → success ; Refusée, Annulée/refused → error ; En attente de validation, En cours de traitement/waiting → warning ; Brouillon/draft → info ; tout autre libellé → default (rose #FEE7FC/#6E445A, le style par défaut de DsfrBadge).

La maquette Figma (composant « Badge Statut Principal ») ajoute un 7e état, Terminée, dessiné avec le même style que Brouillon (bleu info). Mais Terminée n'a aucun cas dans le switch de BadgeState.vue ci-dessus : il tombe donc dans le default et s'affiche en rose, pas en bleu.

Mapping state → type

const type = computed(() => {
      switch (props.state) {
        case 'Validée':
        case 'validated':
          return 'success'
        case 'Refusée':
        case 'Annulée':
        case 'refused':
          return 'error'
        case 'En attente de validation':
        case 'En cours de traitement':
        case 'waiting':
          return 'warning'
        case 'Brouillon':
        case 'draft':
          return 'info'
        default:
          return 'default' // ← "Terminée" tombe ici, pas de case dédié
      }
    })
