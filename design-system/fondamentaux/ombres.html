Ombres & élévation

3 niveaux d'élévation DSFR. Source : Figma « DSFR - v1.15.0 - Fondamentaux » (page Ombres). Déjà implémentés à l'identique dans le code — aucun écart constaté.

🔗 Documentation officielle DSFR : Ombre et élévation

Démo

--shadow-raised
--shadow-overlap
--shadow-lifted

Valeurs

TokenUsageLightDarkClasse Tailwind (code)
--shadow-raisedLéger relief — cartes, boutons au repos0 2px 6px 0 rgba(0,0,18,.16)0 2px 6px 0 rgba(0,0,18,.32)shadow-dsfr-sm
--shadow-overlapÉlément superposé — menus déroulants, popovers0 4px 12px 0 rgba(0,0,18,.16)0 4px 12px 0 rgba(0,0,18,.32)shadow-dsfr-md
--shadow-liftedÉlément flottant au-dessus du contenu — modales, drawers0 6px 18px 0 rgba(0,0,18,.16)0 6px 18px 0 rgba(0,0,18,.32)shadow-dsfr-lg

Cohérence avec le code

Les 3 classes shadow-dsfr-sm / shadow-dsfr-md / shadow-dsfr-lg de tailwind.config.ts reproduisent exactement les valeurs light de raised/overlap/lifted (mêmes offsets, mêmes flous, même alpha 16%). Aucune variante dark définie côté Tailwind pour l'instant — à ajouter si le mode sombre est un jour activé sur la plateforme.
