Boilerplate de page

Point de départ minimal pour esquisser rapidement une nouvelle page statique conforme à l'identité JVA/DSFR — pour une maquette ou un prototype, pas du code de production. Copiez ce squelette, adaptez le contenu.

Cette page et les deux gabarits qui suivent documentent des schémas de composition (comment assembler les composants déjà catalogués sur une page entière), et non des composants individuels. Ils s'appuient sur l'analyse de 3 maquettes Figma réelles : édition du profil bénévole, page mission, page d'accueil.

Squelette HTML à copier

Le <head> ci-dessous reprend celui utilisé sur toutes les pages de ce design-system : polices Marianne, CSS DSFR, script de thème clair/sombre. Adaptez les chemins relatifs (../) à l'emplacement réel de votre fichier.

<!doctype html>
<html lang="fr">
<head>
  <title>Titre de la page</title>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="../dsfr.min.css">
  <script>
    document.documentElement.setAttribute("data-fr-theme",
      matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light");
  </script>
  <style>
    @font-face { font-family: Marianne; src: url('../fonts/Marianne-Regular.woff2') format('woff2'); font-weight: 400; }
    @font-face { font-family: Marianne; src: url('../fonts/Marianne-Bold.woff2') format('woff2'); font-weight: 700; }
    body{ margin:0; font-family:Marianne,-apple-system,'Segoe UI',Roboto,sans-serif; }
    .container{ max-width:1200px; margin:0 auto; padding:0 1.5rem; }
    @media (min-width:1248px){ .container{ padding:0 120px; } }
  </style>
</head>
<body>
  <!-- En-tête : cf. LayoutHeader -->
  <header>…</header>

  <!-- Fil d'Ariane : cf. DsfrBreadcrumb -->
  <nav class="container">…</nav>

  <main class="container">
    <!-- Contenu de la page -->
  </main>

  <!-- Pied de page : cf. LayoutFooter -->
  <footer>…</footer>
</body>
</html>

Convention de conteneur

Les pages JVA respectent un conteneur de contenu de 1200px de large maximum, centré, avec des marges externes qui s'élargissent avec la fenêtre — jusqu'à environ 120px de chaque côté en desktop large (mesuré sur la maquette Figma de la page d'accueil). En dessous du point de rupture LG, revenir aux gouttières standards DSFR de 16 à 24px — voir Grille & points de rupture.

Conteneur de contenu — 1200px max

Les zones hachurées représentent les marges externes fluides. Ni BaseContainer2Cols ni les classes Tailwind existantes n'implémentent explicitement cette valeur de 120px aujourd'hui : c'est un candidat d'homogénéisation à vérifier avec l'équipe dev plutôt qu'une valeur figée à copier telle quelle.

En-tête et pied de page

Ne redessinez pas l'en-tête ou le pied de page : reprenez la structure déjà documentée dans LayoutHeader et LayoutFooter. Pour le fil d'Ariane sous l'en-tête, voir DsfrBreadcrumb.
